## Short strategy review

### Prioritize for organic (SEO)

Win durable rankings where we already have (or nearly have) content and buyer literacy intent is high:

1. **ARR methodology cluster** — ARR waterfall, ARR vs GAAP, ARR governance, billing vs CRM ARR (gap), NRR vs GRR  
2. **Board reporting / board pack** — live post + homepage theme; expand internal links  
3. **SaaS FP&A / financial intelligence** — homepage, pricing, demo, glossary hub language  
4. **Cash forecast + scenario / variance** — planned posts; bridge from board ARR–cash–P&L piece  
5. **Glossary definitions** — NRR, GRR, waterfall, ARR as supporting entry points (definition → pillar)

Organic goal: impressions → qualified sessions on pillar posts and conversion pages (`/book-demo`, `/request-quote`).

### Prioritize for paid (Google Ads)

Buy intent we cannot wait months to rank for, and terms that map cleanly to lead-form conversion:

1. **SaaS FP&A software** / FP&A software for SaaS  
2. **Board reporting software** / SaaS board reporting  
3. **ARR reporting software** / ARR waterfall (careful: mix of how-to vs buy)  
4. **AI CFO Copilot** / explainable AI for SaaS finance  
5. **Financial intelligence platform** (SaaS-qualified copy)  
6. **Executive reporting / board deck automation** (transactional modifiers)

Ads goal: **Submit lead form** (demo / quote). Page views only as secondary measurement.

### Gaps (content or landing)

| Gap | Why it matters | Suggested next move |
| --- | --- | --- |
| Billing vs CRM ARR post | High reconciliation pain; no dedicated URL | Brief + publish P1 pillar |
| SaaS cash forecast post | Bridges board pack → product; soft demo CTA | Brief tied to live board post |
| Dedicated AI CFO Copilot landing | Strong ads theme; homepage/blog only today | Lightweight `/` section or feature URL for ads |
| Scenario analysis / variance landing | Ads/SEO supporting theme under-served | Blog or feature page after cash forecast |
| GSC validation | Priorities are qualitative until data | Track queries in GSC after GRR/NRR indexing |

### Avoid list (wrong intent — especially ads negatives)

Do **not** bid or optimize as if we sell:

- Bookkeeping / bookkeeper  
- Payroll / payroll software  
- Tax software / tax filing  
- AP automation / invoice OCR  
- QuickBooks setup / “accounting software” as primary  
- Generic ChatGPT / “ChatGPT for finance” wrappers  
- NetSuite / Sage Intacct / Salesforce **replacement** (we connect; we do not replace SoR)  
- SOC 2 certified claims in ads/SEO copy (not certified)

Also avoid treating **AI OS / Finance OS** as the primary keyword wager for either channel.
