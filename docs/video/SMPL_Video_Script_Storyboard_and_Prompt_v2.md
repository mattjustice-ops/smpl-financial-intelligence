## What changed in v2, and why

- **Opening concept replaced.** The original "one number fans out to five systems" device was too close to the reference video's actual pitch (unification) rather than SMPL's real differentiator (traceability/evidence). New device: the same number, looked at in different moments, with no way to trace why it's true. This is a sharper, more original idea — not a patch, a real improvement.
- **Illustrative number changed.** `$42.1M` → `$18.7M ARR`, and it's now explicitly labeled as ARR rather than an unlabeled dollar figure, tying it to the specific metric SMPL differentiates on. Still illustrative — swap for a real approved figure if one becomes available.
- **We are not mirroring the reference video's structure beat-for-beat.** Where a shot's device still legitimately fits (the systems-unification visual, now relocated to Shot 4 instead of duplicated in both Shot 1 and Shot 4), keep it. Where it doesn't serve SMPL's actual story, drop it.
- **Production Quality Standards section added** (near the end) — durable guidance for every remaining shot, not just Shot 1, based on specific gaps identified in the first two builds.

Rather than branching into five systems, the same number recurs 2–3 times across the shot — each instance paired with a different, subtle context cue (a time-of-day indicator, then "Board Deck — Last Quarter") — and each instance is visually disconnected from any source: no line, no trail, nothing underneath it. ## Part 3 — Production Quality Standards

Durable guidance for every shot from here forward, based on specific gaps found in the first two builds — not just notes for Shot 1.

### Motion polish
- Smooth spring-based easing on every animated element — nothing linear, nothing bouncy by default
- Deliberate stagger between elements so multiple things don't move at identical speed simultaneously
- Consistent stroke weights across every diagram element
- If any camera/parallax movement is used, one slow deliberate drift only — never multiple competing motions at once, which reads as shakiness even when no single element is individually wrong

### Voiceover quality
- Current pipeline uses Edge TTS (free tier). If the project setup allows it, prefer a premium neural TTS provider (e.g. ElevenLabs) for the final render — the naturalness and prosody gap between free and premium TTS is significant and was specifically noticed on review
- This likely requires an API key and small per-minute cost — flag this tradeoff explicitly to the team rather than swapping providers silently
- Keep voice selection consistent across all 8 shots once chosen — do not mix voices between shots

### Creative independence from the reference video
- We are intentionally not mirroring the reference video's structure, timing, or visual devices beat-for-beat anymore
- Where a shared device (dark background, kinetic typography, node-and-line diagrams) is simply good practice for this genre of video, keep it
- Where a device was borrowed specifically because the reference used it (the original five-way fan-out as the opening beat), prefer an original alternative that serves SMPL's actual differentiators instead
