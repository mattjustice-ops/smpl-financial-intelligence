# Creative Direction Update – SMPL.ai Brand Film (v3.1)

**IMPORTANT:** Not a redesign or rewrite. Preserve storyboard, pacing, messaging, structure.
Focus: production quality, realism, visual storytelling.

## Core principle — Recognition Over Reading

Prefer visual recognition over text. If the audience can recognize a Salesforce pipeline, a NetSuite period close, an Excel forecast model, or a PowerPoint board deck, show those visuals instead of writing "CRM," "ERP," "Spreadsheet," or "Presentation." Understandable muted.

## Key improvements

1. Replace abstract visuals with recognizable system UI recreations (not copyrighted screenshots)
2. Synchronize narration with visuals — never describe what isn't shown
3. Build recognition instead of explanation
4. Realistic lived-in finance desktop with believable content
5. Layer applications gradually (workload grows)
6. Emotional storytelling — quiet, recognizable gestures
7. Preserve pacing — do not rush
8. Preserve SMPL reveal; converge apps elegantly (Scenes 4–5)
