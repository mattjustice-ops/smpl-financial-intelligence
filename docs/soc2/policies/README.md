# Policy drafts (SOC 2 Type I readiness)

**All files in this folder are DRAFT — NOT APPROVED** unless the policy index says otherwise.

They exist so readiness checkboxes can move to “drafts ready for approval.” They are **not** evidence of SOC 2 compliance and must not be presented to customers as approved company policy until the executive sponsor (Matt Justice) signs them.

## How Matt approves

1. Read each P01–P12 draft (or the core set you accept).
2. In each file’s **§ Approval** table: replace `_DRAFT — not signed…_` with your name (or “Approved”) and the date.
3. Record the same in [../04_policy_index.md](../04_policy_index.md) (Status → **Approved**, Approved date, Approval record table).
4. Optionally reply in chat/PR: `approve P01–P12` (agent will sync PROGRESS + `progress.ts`).
5. Do **not** mark the public `/compliance` page as Type I complete — approval ≠ CPA report.
